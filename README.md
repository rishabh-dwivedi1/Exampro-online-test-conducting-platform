🚀 ExamPro – Online Examination Platform

ExamPro is a modern Online Examination Platform developed using Django, HTML, CSS, JavaScript, and SQLite. The project is designed to provide a secure, efficient, and user-friendly environment for conducting online examinations and managing student performance.

The platform allows administrators to create and manage exams, while students can securely log in, attempt tests, and instantly view their results. The system focuses on simplicity, responsiveness, and real-world usability.

✨ Features
🔐 Secure Login & Authentication System
📝 Online Exam Creation and Management
👨‍🎓 Student Dashboard
📊 Instant Result Generation and Performance Tracking
⏱️ Timed Examination Support
📱 Responsive and User-Friendly Interface
🗂️ Organized Database Management using Django ORM
🛠️ Technologies Used
Backend: Django (Python)
Frontend: HTML, CSS, JavaScript
Database: SQLite
Tools: VS Code, GitHub
